# docs/lessons.local.md — personal lessons (EXAMPLE)

This is a **template**. Copy it to `docs/lessons.local.md` (gitignored). It holds
machine or workflow facts that are true of **you**, not of every contributor.

Facts that reproduce for **everyone** belong in the shared
[`lessons.md`](lessons.md) instead — that file is for the project's measured
environment facts. This file is for the rest: your machine's quirks, your
shortcuts, your reminders.

Use the shared shape: **Symptom → Cause → Fix → Enforced by**. "Enforced by" may
be empty here — a personal note is a reminder, not a rule.
