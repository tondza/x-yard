Scenario 1 of 8

The Fugitive's own turn

You are the hidden player, and this is the half of the rule nobody else sees.

Vulture sees their own icon — no ghost marker and no belief shading, because they already know where they are. Foot, taxi and bus paths bend along the streets; the scooter is a 2-edge double move; metro is visibly disabled because n6 is a hub, not a terminal, so the rule teaches itself.

Scenario 2 of 8

Agent deducing

The most important screen in the set: what an Agent actually knows at turn 7.

No Fugitive is drawn at all. There is a ghost at the last-known node, belief shading whose intensity is likelihood, and a top-3 badge — never a candidate list. The public log (mode only, destination hidden) is the deduction input, and bus reads "no line at n5" because a standard street node has no bus.

Live version: design/moodboard/round-03-mobile/s2-agent-deduction.html
Scenario 3 of 8

The Reveal Pulse

The dramatic beat, and the reason the whole design hangs together.

The pulse runs before the Agent phase, so Falcon can still act this turn — and n6, where Vulture stands, is reachable by foot. Belief shading is gone because knowledge is now exact. Note: the turn model has since changed, so where the pulse sits relative to the new timed windows is still open.

Live version: design/moodboard/round-03-mobile/s3-reveal-pulse.html
Scenario 4 of 8

Capture and result

One clear hierarchy instead of a dialog.

A full-screen surface, not a modal — the MVP has zero modals. Capture landed on turn 12 of 16, two pulses survived, capture range one edge, and the tickets spent per seat. Two actions and nothing else.

Live version: design/moodboard/round-03-mobile/s4-capture-result.html
Compare with 2

The same screen in style H

Identical state to scenario 2 — only the look changes, so this is the fair comparison.

Painterly, pure top-down, night. The product recommendation on file is to ship F and treat H as a later art pass, but the trade is real: H is far more atmospheric, while belief badges sit further from their stations and the city detail competes with the markers. No fog layer — the original H fog was rejected as implying a mechanic that does not exist.

Live version: design/moodboard/round-03-mobile/s5-agent-deduction-night-H.html
Scenario 6 of 8

Desktop enhancement

Proof that mobile-first does not paint us into a corner.

The same phone Board grown: the bottom tray becomes a side rail, the log strip a persistent panel, and the extra width buys map — 22 stations around the unmoved original 9 — rather than a different game. Nothing is hover-only or drag-only, so every affordance still exists on the phone. (Shown at 1440 × 900, so it is wider than the phone screens around it.)

Live version: design/moodboard/round-03-mobile/s6-desktop-enhancement.html
Scenario 7 of 8

The Agent window, live

Four Agents, one 30-second clock, and moves landing as they happen.

The clarified turn model: every Agent moves inside the same 30-second window, and a move becomes visible to the other Agents the moment it is made — so a later mover acts on more information. Osprey and Merlin have already moved; Falcon and Harrier are still deciding, and the shared clock is what everyone waits on. Shown at prototype scale (1 Fugitive + 4 Agents).

Live version: design/moodboard/round-03-mobile/t1-agent-window.html
Scenario 8 of 8

The Fugitive window, live

The same 30-second window — but only the Fugitives can see this screen.

Four Fugitives, all visible to each other, because positions are shared inside a faction. Vulture is the viewer; Kestrel and Magpie have already moved, Shrike is still deciding. Agents see none of this — only the mode log, plus the pulse every fifth turn. Shown at MVP scale (4 Fugitives).

Live version: design/moodboard/round-03-mobile/t2-fugitive-window.html
