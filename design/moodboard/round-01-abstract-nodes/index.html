What is identical across all four

Every mockup renders the same board and the same game state, so only the art direction varies:
  • The same 8-node / 21-edge scaffold graph — 16 taxi, 3 bus, 1 metro, 1 special.
  • Safe House at s7, Black Market at s6.
  • Turn 6 of 24. Last Reveal Pulse turn 3, next turn 8.
  • F1 revealed at s3; F2 hidden since turn 3; F3 hidden with heavy contraband.
  • Agents at s7, s4, s8.
  • The same five ticket-log rows, including one Unknown Transport.
  • The same probability spread for F2: s2 40%, s3 25%, s8 20%, s6 15%.

Decisions this round is asking for

  1. Light or dark? A is light-neutral, C light-warm, B and D dark. This moves perceived tone more than anything else.
  2. Tone: competent tool (A), surveillance thriller (B), analog investigation (C), or competitive esports (D)?
  3. How hidden information is drawn — see the four treatments above. Sub-question: how much math belongs on screen? B shows entropy in bits; A shows percentages; C shows pencil estimates. More telemetry reads as simulator, less as board game.
  4. Density: A is spacious and immediately legible, B is dense and rewards mastery, C is layered, D is bold. Dense screens raise the learning cliff.
  5. Typography: sans (A), monospace-forward (B), serif + typewriter (C), heavy geometric sans (D).
  6. Map rendering: flat transit diagram (A), glowing grid (B, D), or paper chart (C)? How far should the map depart from a literal transit diagram?
  7. Transport-mode colours: quiet and functional (A) or a loud part of the identity (B, D)? All four chose different colours for the same four modes — the mapping is still open.
  8. Faction-specific views: A toggles Fugitive/Agent, B has "viewing as", D labels "faction · yours". Does the UI genuinely differ per faction, or is it one screen with an overlay?
  9. Node identity: the mocks use s1…s8; C invented in-world names ("Kentish Row", "Aldgate Spur"). Do nodes get real place names? That is world-building as much as UI, and it interacts with Yards being named cities.
  10. Reveal Pulse prominence: header countdown (A, B), paper bookkeeping (C), or a certainty meter (D)? It is the heartbeat of the game.

Not covered yet

These are directional sketches, not final screens. Still open: mobile and small viewports, accessibility (contrast and colour-blind safety for the mode colours), hover/focus/disabled states, motion design, lobby and matchmaking, the end-of-Yard summary, spectating, and how the board behaves at the ~150-node scale the vision implies — all four mocks show 8 nodes.
